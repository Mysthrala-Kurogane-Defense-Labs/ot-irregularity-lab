# Dataset generation

Each run writes `telemetry.parquet`, `ground_truth.json`, `run_metadata.json`, and the resolved `scenario.yaml`. Ground truth schema v1.1.0 includes event intervals and actual operating-regime intervals even if regime tags are hidden from telemetry. CSV and JSONL telemetry exports are opt-in. Batch suites write independent seeded runs under `train/`, `validation/`, and `test/`, plus model-ready concatenated `train.parquet`, `validation.parquet`, and `test.parquet` files at the dataset root. The `dataset_manifest.json` records suite/simulator/schema versions, counts, disjoint seeds, observations, per-run and partition artifact hashes, and realized class, event, asset, and regime distributions. Every concrete sampled parameter is recorded in its run scenario so `replay` can reproduce that run exactly. The suite YAML is copied into the dataset root. The manifest describes the generated dataset; it is not a signed provenance attestation.

Batch creation requires a new output path, stages the complete dataset in a temporary sibling directory, and renames it into place only after generation succeeds. Failed generation leaves no partial output at the requested path.

Partitions use distinct seeds and run IDs. A release manifest records resolved scenario hashes, observation counts, class, event, asset, and regime distributions, generator arguments, software lockfile hash, and data license. Public datasets contain synthetic, generated, non-customer data only.

The randomized `training-v0.2` suite mixes normal and fault-bearing runs with weighted asset/operating profiles and explicit type-specific parameter distributions. It declares CC BY 4.0 for generated outputs. Create it with `uv run ot-lab dataset create --suite suites/training-v0.2.yaml --runs 3000 --seed 20261003 --output datasets/ot-irregularity-training-v0.2`. The default 35%/65% normal/event-bearing mix is a benchmark design choice, not a claim about plant failure prevalence. A resumable large-scale writer is not included. Challenge generation draws a hidden runtime seed and concrete ranged parameters in an evaluator-controlled process, does not persist the resolved scenario/seed, and discards the temporary case after scoring.

The public 1,000-run release is available from the [OT Irregularity Dataset v0.2.0 release](https://github.com/Mysthrala-Kurogane-Defense-Labs/ot-irregularity-lab/releases/tag/dataset-v0.2.0).
