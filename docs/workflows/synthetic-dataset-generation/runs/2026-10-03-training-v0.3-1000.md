# OT Irregularity Training Dataset v0.3.0, 1,000 runs

## Generation

- Simulator: 0.3.0; telemetry schema 1.0.0; ground-truth schema 1.1.0.
- Suite: `suites/training-v0.2.yaml` v0.2.0, unchanged from the v0.2 dataset. Suite SHA-256: `a768415b78245f671ac41edb75b249e9c8ab0523c1088aa9848b9c62f613e091`.
- Command: `uv run --python 3.12 ot-lab dataset create --suite suites/training-v0.2.yaml --runs 1000 --seed 20261004 --output datasets/ot-irregularity-training-v0.3-release --resume`.
- Master seed: 20261004; all 1,000 run seeds are distinct and disjoint from the v0.2 master seed 20261003.
- Data license: CC BY 4.0, declared in the manifest and included as `DATASET_LICENSE.txt`.
- Manifest declares synthetic, generated, non-customer data.

## Realized contents

- 1,000 runs and 8,477,689 telemetry observations.
- Partitions: train 700 runs / 5,904,577 rows; validation 150 / 1,192,770 rows; test 150 / 1,380,342 rows.
- Run classes: 359 normal and 641 event-bearing. This is the suite's seeded outcome, not an estimate of industrial event prevalence.
- Asset occurrences: CNC 578, pump 574, compressor 421, conveyor 411. Multi-asset profiles make the sum exceed run count.
- Event counts: bearing degradation 67; cavitation 40; cooling degradation 76; mechanical overload 86; sensor drift 73; sudden spike 62; sensor stuck 56; sensor bias 82; missing telemetry 74; single signal loss 66; asset communication loss 50; quality degradation 50; regime mismatch 71; multivariate novelty 59; maintenance activity 47.

## Integrity and replay

- Every run telemetry, ground truth, metadata and scenario hash in the manifest was checked; partition hashes and row counts were checked. All 1,000 run seeds are unique.
- Replayed `train/train-00001` (normal, 2,862 rows) and `test/test-00001` (two events, 24,600 rows); Parquet rows and ground truth matched exactly.
- The archive contains 4,006 files, including 1,000 independent ground-truth files, resolved scenarios, telemetry runs, manifest, suite and dataset license. The merged train/validation/test Parquet files contain telemetry columns only.
- ZIP CRC validation passed. Archive size: 139,044,425 bytes. SHA-256: `d1d9a36054f4f4e0798a77723a98375120857a4a4f8f33103dbe7f935065c4c8`.
- The archive writer uses sorted paths and fixed timestamps for repeatable packaging from identical source bytes.

## Evidence boundaries

The four process models remain simplified and are not calibrated digital twins. Source notes and their limits are in `CALIBRATION.md`. The dataset is intended for reproducible model-agnostic experimentation; the realized class mix and fault counts do not represent field frequency. Dataset release CI verifies software, not the uploaded artifact; artifact hashes and generation evidence are recorded here and in `dataset_manifest.json`.
