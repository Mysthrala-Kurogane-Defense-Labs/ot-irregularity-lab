# OT Irregularity Training Dataset v0.2.0, 1,000 runs

## Scope and artifact

- Generated with `suites/training-v0.2.yaml`, simulator 0.2.0, telemetry schema 1.0.0, ground-truth schema 1.1.0.
- Command: `uv run ot-lab dataset create --suite suites/training-v0.2.yaml --runs 1000 --seed 20261003 --output datasets/ot-irregularity-training-v0.2-release`.
- Artifact: `datasets/ot-irregularity-training-v0.2-release/`; data license: CC BY 4.0; manifest declares `synthetic=true`, `generated=true`, and `customer_data=false`.
- Research informed coverage design only. No public source dataset records, traces, labels, or simulator code were copied. See [synthetic dataset design](../../../../SYNTHETIC_DATASET_DESIGN.md).

## Generated mix

- 1,000 independently seeded runs and 8,399,914 telemetry observations.
- Partitions: train 700 runs / 5,925,933 rows; validation 150 / 1,337,787; test 150 / 1,136,194.
- Realized run classes: 326 normal (32.6%), 674 event-bearing (67.4%). Suite target probabilities are 35%/65%; these are sampling weights, not field incident prevalence.
- Asset occurrences: CNC 563, pump 561, compressor 420, conveyor 418. Multi-asset profiles mean counts sum above run count.
- Event counts: bearing degradation 79; cavitation 59; cooling degradation 55; mechanical overload 74; sensor drift 77; sudden spike 69; sensor stuck 57; sensor bias 80; missing telemetry 91; single signal loss 63; asset communication loss 62; quality degradation 57; regime mismatch 61; multivariate novelty 63; maintenance activity 43.
- Regime episodes: OFF 235, IDLE 873, WARMUP 1,962, LOW_LOAD 1,720, NORMAL_LOAD 3,232, HIGH_LOAD 1,727, COOLDOWN 1,962, MAINTENANCE 436.
- Validation found zero events with empty affected-signal lists; randomized events on the same asset did not overlap.

## Limits and publication status

The processes use simplified models and generated noise; distribution weights are benchmark choices, not estimates of industrial failure frequency. These data do not calibrate real plant dynamics or validate field detector performance.
