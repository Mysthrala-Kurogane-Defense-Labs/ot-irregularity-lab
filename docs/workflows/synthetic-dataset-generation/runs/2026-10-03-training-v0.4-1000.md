# OT Irregularity Training Dataset v0.4.0, 1,000 runs

## Generation

- Suite: `suites/training-v0.2.yaml`, suite version `0.2.0`, dataset version `0.4.0`.
- Command: `uv run ot-lab dataset create --suite suites/training-v0.2.yaml --runs 1000 --seed 20261005 --workers 4 --output <dataset-path> --resume`.
- Simulator `0.3.1`; telemetry schema `1.0.0`; ground-truth schema `1.1.0`.
- Seed: `20261005`; four workers; generation completed in 37.58 seconds.
- 8,503,599 observations in 700/150/150 train/validation/test runs.
- 347 normal runs and 653 runs with injected events.
- Event types: `asset_communication_loss`, `bearing_degradation`, `cavitation`, `cooling_degradation`, `maintenance_activity`, `mechanical_overload`, `missing_telemetry`, `multivariate_novelty`, `quality_degradation`, `regime_mismatch`, `sensor_bias`, `sensor_drift`, `sensor_stuck`, `single_signal_loss`, `sudden_spike`.
- Asset classes: CNC, pump, compressor and conveyor.
- Declared dataset license: CC BY 4.0.

## Partition release artifacts

The release package includes separate telemetry and labels archives. Telemetry archives contain Parquet without ground truth. Labels archives contain ground truth and allowlisted evaluation metadata; they omit run seeds, source scenarios and generation metadata. For blind evaluation, keep label archives separate from model inputs.

## Validation and limits

- All source Parquet, ground-truth and run-metadata hashes were checked by the packaging command.
- All six ZIP archives were read in full; their SHA-256 values match the release manifest.
- Telemetry archives were checked to contain no ground truth; label manifests declare no seeds or scenarios, and evaluation metadata was checked for seed/scenario fields.
- Dataset packager tests, full pytest suite and Ruff passed locally before release commit.
- This is synthetic generated data. Distribution reflects this suite's sampler and does not estimate real industrial fault prevalence. The release is not public until a GitHub release URL is added here.
