# Training v0.5 distribution validation

## Objective

Check that the new compressor `air_leak` family is reachable at a useful suite rate, generated events are deterministic and placeable, and replay reconstructs telemetry and ground truth exactly.

## Changes

- Added compressor-containing cell and mixed-plant profiles to `training-v0.3` and `challenge-v0.2`. Existing standalone assets and prior suite versions remain unchanged.
- Replaced retry-limited random event placement with deterministic seeded backtracking over compatible assets and feasible time gaps. Sampled parameters that depend on asset signal inventory are now resolved after selecting a compatible asset.
- Tests check non-overlap and reproducibility over 120 seeds, and verify event-family coverage over an independent 300-seed sample. The generated diagnostic manifest also contains 300 unique seeds.
- Review found and removed parameter draws from infeasible search branches. The final review confirms sampled effects are resolved once a feasible asset/time placement exists.

## Validation

- Python 3.13.11 / NumPy 2.5.3 / Polars 1.44.2, WSL: `uv run --extra dev --group lint pytest -q` — 143 passed, 1 skipped. `uv run --extra dev --group lint ruff check src tests` — passed.
- Generated 300 runs using `suites/training-v0.3.yaml`, seed `20261005`, four workers. The manifest records 3,145,105 observations, 210/45/45 train/validation/test runs, 96 normal and 204 event-bearing runs, 16 event families, and 12 air-leak events. All 300 run seeds are unique. Air leak appeared in train; its absence from validation/test in this finite sample is recorded, not hidden.
- Replayed `train-00022`: all 16,350 telemetry rows compare equal and `ground_truth.json` compares equal.
- A first pre-adjustment 300-run diagnostic had only 3 air leaks due to the low probability of selecting compressor-containing profiles; this informed the profile-weight change. It is retained only as local ignored output and is not part of the repository or a release.
- Pattern references and license boundaries are documented in [DATASET_PATTERN_REVIEW.md](../../../../DATASET_PATTERN_REVIEW.md). MetroPT informed qualitative coupling only; injected ranges are not estimates of field prevalence or fitted physical parameters.

## Limitations and next steps

- No public v0.5 dataset artifact has been packaged or published. This is a validation sample, not a release candidate; event/asset/partition distribution needs broader inspection and release checks.
- The 300-run draw did not realize air leaks in validation/test. Suite probability and asset-profile design can be tuned as benchmark design choices, or partitions can be stratified by coverage, but either change requires a new suite version and explicit methodology to avoid leakage.
- The compressor model remains simplified and not a calibrated digital twin. Public real telemetry was not copied into generated artifacts.
- Full CI and the current PR are still pending.
