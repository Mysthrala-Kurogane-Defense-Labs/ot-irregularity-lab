# Training v0.5 distribution validation

## Objective

Check that the new compressor `air_leak` family is reachable at a useful suite rate, generated events are deterministic and placeable, and replay reconstructs telemetry and ground truth exactly.

## Changes

- Added compressor-containing cell and mixed-plant profiles to `training-v0.3` and `challenge-v0.2`, and raised the v0.3 `air_leak` template weight from 0.8 to 2.0 after the first diagnostic draw underrepresented it. Existing standalone assets and prior suite versions remain unchanged.
- Replaced retry-limited random event placement with deterministic seeded backtracking over compatible assets and feasible time gaps. Sampled parameters that depend on asset signal inventory are now resolved after selecting a compatible asset.
- Tests check non-overlap and reproducibility over 120 seeds, and verify event-family coverage over an independent 300-seed sample. The generated diagnostic manifest also contains 300 unique seeds.
- Review found and removed parameter draws from infeasible search branches. The final review confirms sampled effects are resolved once a feasible asset/time placement exists.
- To guarantee rare-family visibility in each partition, v0.3 now declares `coverage_by_partition: {air_leak: 50}`. For each partition, the generator forces up to the smaller of that count and 10% of the partition run count to contain the required family. It selects a compatible asset profile and still assigns a distinct run seed; remaining runs keep the versioned weighted-random distribution. Tests confirm each partition retains normal and anomalous runs and that the forced sample is deterministic. This deliberately changes class balance for those forced runs.

## Validation

- Python 3.13.11 / NumPy 2.5.3 / Polars 1.44.2, WSL, current tree: `uv run --extra dev --group lint pytest -q` — 145 passed, 1 skipped. `uv run --extra dev --group lint ruff check src tests` — passed.
- Initial generated draw before the event-weight adjustment: 300 runs, seed `20261005`, four workers, 3,145,105 observations, 12 air leaks (all train), 16 event families. This exposed poor finite-partition coverage.
- Final generated draw after profile and event-weight adjustments: 300 runs, same master seed, four workers, 3,145,798 observations, 96 normal and 204 event-bearing runs, 16 event families, and 26 air leaks (21 train, 4 validation, 1 test). All 300 run seeds are unique.
- Evaluation-set sizing draw: 3,000 runs with seed `20261006` and four workers produced 30,920,238 observations, 1,082 normal and 1,918 event-bearing runs, and 2,849 total events across all 16 families. It realized 272 air leaks (196 train, 32 validation, 44 test); train/validation/test contain 2,100/450/450 distinct runs and all 3,000 run seeds are unique.
- Replayed `train-00001` from the final weighted suite: all 12,480 telemetry rows compare equal and `ground_truth.json` compares equal.
- Fresh 300-run coverage-policy draw: 3,143,875 observations, 81 normal and 219 anomalous runs, all 300 seeds distinct, 53 air leaks (40 train, 8 validation, 5 test). Partitions retain both normal and anomalous cases. This confirms family presence for this size/seed but does not establish statistical adequacy for test metrics.
- Pattern references and license boundaries are documented in [DATASET_PATTERN_REVIEW.md](../../../../DATASET_PATTERN_REVIEW.md). MetroPT informed qualitative coupling only; injected ranges are not estimates of field prevalence or fitted physical parameters.

## Limitations and next steps

- No public v0.5 dataset artifact has been packaged or published. The 3,000-run sizing draw produced 44 air-leak events in test, which is a starting validation volume, not a statistical power guarantee or release decision.
- A 3,000-run release-size artifact should be regenerated with the current coverage policy and reviewed for realized distributions, class/event balance, event metric uncertainty, hashes, deterministic packaging, and license before release.
- The compressor model remains simplified and not a calibrated digital twin. Public real telemetry was not copied into generated artifacts.
