# Training v0.5 distribution validation

## Objective

Check that the new compressor `air_leak` family is reachable at a useful suite rate, generated events are deterministic and placeable, and replay reconstructs telemetry and ground truth exactly.

## Changes

- Added compressor-containing cell and mixed-plant profiles to `training-v0.3` and `challenge-v0.2`, and raised the v0.3 `air_leak` template weight from 0.8 to 2.0 after the first diagnostic draw underrepresented it. Existing standalone assets and prior suite versions remain unchanged.
- Replaced retry-limited random event placement with deterministic seeded backtracking over compatible assets and feasible time gaps. Sampled parameters that depend on asset signal inventory are now resolved after selecting a compatible asset.
- Tests check non-overlap and reproducibility over 120 seeds, and verify event-family coverage over an independent 300-seed sample. The generated diagnostic manifest also contains 300 unique seeds.
- Review found and removed parameter draws from infeasible search branches. The final review confirms sampled effects are resolved once a feasible asset/time placement exists.

## Validation

- Python 3.13.11 / NumPy 2.5.3 / Polars 1.44.2, WSL: `uv run --extra dev --group lint pytest -q` — 143 passed, 1 skipped. `uv run --extra dev --group lint ruff check src tests` — passed.
- Initial generated draw before the event-weight adjustment: 300 runs, seed `20261005`, four workers, 3,145,105 observations, 12 air leaks (all train), 16 event families. This exposed poor finite-partition coverage.
- Final generated draw after profile and event-weight adjustments: 300 runs, same master seed, four workers, 3,145,798 observations, 96 normal and 204 event-bearing runs, 16 event families, and 26 air leaks (21 train, 4 validation, 1 test). All 300 run seeds are unique.
- Replayed `train-00022` from the intermediate, pre-weight-adjustment suite: telemetry and ground truth compared exactly. The final weighted suite needs a fresh replay check before publishing v0.5.
- Pattern references and license boundaries are documented in [DATASET_PATTERN_REVIEW.md](../../../../DATASET_PATTERN_REVIEW.md). MetroPT informed qualitative coupling only; injected ranges are not estimates of field prevalence or fitted physical parameters.

## Limitations and next steps

- No public v0.5 dataset artifact has been packaged or published. This is a validation sample, not a release candidate; the single air leak in test is too sparse for stable independent evaluation. A separate challenge suite provides runtime-generated blind cases.
- The suite distribution and explicit numeric effect ranges are synthetic benchmark design choices. A larger training/test sample and review of class/event balance remain needed before release.
- The compressor model remains simplified and not a calibrated digital twin. Public real telemetry was not copied into generated artifacts.
- Full CI and the current PR are still pending.
