# OT Irregularity Training Dataset v0.5.0, 3,000 runs

## Generation

- Generator revision: `46c84120b095ac6c3678c376a031bdf26cfb10b2` on PR #5 branch `feat/metropt-air-leak-pattern`.
- Suite: `suites/training-v0.3.yaml`, suite version `0.3.0`; data license CC BY 4.0.
- Command: `uv run ot-lab dataset create --suite suites/training-v0.3.yaml --runs 3000 --seed 20261008 --workers 4 --output datasets/ot-irregularity-training-v0.5-release-candidate`.
- Simulator `0.4.0`; telemetry schema `1.0.0`; ground-truth schema `1.1.0`.
- Runtime: Python 3.13.11, NumPy 2.5.3, Polars 1.44.2.
- 31,114,700 observations in 2,100/450/450 train/validation/test runs.
- 998 normal runs and 2,002 runs with events. Per partition: train 719 normal/1,381 event-bearing; validation 135/315; test 144/306.
- Event types: all 16 v0.3 suite families. Air leak: 393 events (222 train, 87 validation, 84 test).
- Every asset class (CNC, pump, compressor, conveyor) appears. All 3,000 run seeds are distinct.
- Dataset manifest SHA-256: `e650b7bd140fc518b10eef08b87da15bbc767b835eff8c5afcf1327344d2885b`.

## Replay and partition checks

- Replayed `test/test-00001`, a forced compressor air-leak run. Its 5,040 telemetry rows and ground-truth JSON exactly match the generated source run.
- Recomputed SHA-256 for `train.parquet`, `validation.parquet`, and `test.parquet`; all three match `dataset_manifest.json`.
- Coverage policy: v0.3 requests 50 required air-leak runs per partition, capped at 10% of each partition's run count. The 3,000-run release candidate realizes more (222 train, 87 validation and 84 test), because the remaining runs still sample the weighted randomized distribution. Forced cases use unique run seeds and only the required event family; the rest of each run definition is seeded normally.
- This is synthetic sampling coverage, not field prevalence or a calibrated compressor twin.

## Public package candidate

Prepared under `releases/ot-irregularity-training-v0.5.0-verified/` with separate telemetry and ground-truth-label ZIPs for each partition. Each telemetry ZIP contains only its Parquet file, `DATASET_LICENSE.txt`, and a seed-free `release_manifest.json`. Each labels ZIP contains one ground-truth file and allowlisted evaluation metadata per run, plus a label manifest; it contains no seeds, scenario YAML or generator metadata.

## Publication status and limits

- This record describes a locally verified release package; it is not a claim that a GitHub dataset release already exists.
- The simulator equations and fault effects remain intentionally simplified; public MetroPT-3 data informed qualitative event coupling only and was not copied into the artifacts.
- Any benchmark report should retain per-partition class/event distributions and avoid interpreting suite weights as industrial rates.
