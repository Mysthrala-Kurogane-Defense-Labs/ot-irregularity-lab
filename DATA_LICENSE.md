# Dataset licensing policy

Software in this repository is licensed under Apache-2.0. Software licensing does not automatically license generated datasets.

Each published dataset release must include its own `LICENSE` or a clear license declaration in the release metadata. CC BY 4.0 is the proposed default because it preserves attribution to the simulator and scenario authors; CC0 may be selected for a specific release only when the maintainers explicitly choose it. Dataset releases must be generated synthetic data and contain no customer or facility data.

No dataset release is included in v0.1.0. Generated local runs are artifacts, not a licensed public dataset release.
