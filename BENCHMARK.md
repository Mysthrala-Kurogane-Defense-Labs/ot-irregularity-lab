# Model-agnostic benchmark protocol

Submission contract: a process receives only `input.parquet` and writes `output.jsonl` records with `asset_id`, `window_start`, `window_end`, and `irregularity_score` in `[0,1]`. Optional `classification` and `evidence` are descriptive. The platform imports no detector implementation.

`ot-lab benchmark --run runs/cnc-0042 --predictions results/model-a.jsonl --output results/model-a` evaluates event intervals. A prediction counts for an event when it overlaps the event's observed interval; the default event detection threshold is 10% duration coverage and prediction score threshold is 0.5. Both are configurable. It writes `metrics.json` and `report.html` with event precision/recall/F1, window precision/recall/F1, event detection rate, window-level PR-AUC (a window is positive when event overlap reaches configured coverage), false-positive counts/rates, first-detection latency, and event coverage. The generic `precision`/`recall`/`f1` fields alias event metrics. Exposure uses summed asset observation spans from Parquet.

Use `ot-lab compare --run runs/cnc-0042 --predictions results/model-a.jsonl results/model-b.jsonl --output results/comparison` to score several prediction files against the same run and create `comparison.json` plus per-model reports.

`ot-lab run-container --run RUN_DIR --image IMAGE --output predictions.jsonl` uses Docker with no network, read-only root, dropped capabilities, no-new-privileges, non-root uid, resource limits, minimal environment, and only telemetry plus an output directory mounted. Ground truth is not mounted. This baseline profile passed a local Docker smoke run; daemon/host compromise, kernel escape, and adversarial images are outside its guarantee. `ot-lab challenge --suite SUITE --image IMAGE --output RESULTS` generates a fresh seed in memory, varies configured numeric ranges, runs the container, scores its output, then removes the temporary case. Local end-to-end challenge smoke passed; broader adversarial isolation validation remains outstanding.
